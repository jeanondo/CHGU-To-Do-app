# CHGU-To-Do-app
A personal productivity and task management app built with HTML, CSS, and JavaScript.
This project is part of the CHGU ecosystem and is being developed to improve both programming skills and personal organization.

## Features
- Add tasks
- Delete tasks
- Save tasks with localStorage
- Dynamic task rendering

## Technologies
- HTML
- CSS
- JavaScript
- localStorage

## Goal
The goal of this project is to progressively build a functional and interactive productivity application while learning web development fundamentals step by step.

Plans include:
- Mobile-friendly design
- Task completion tracking
- Notifications/reminders
- CHGU ecosystem integration

## Run Locally
1. Download the project
2. Open the folder
3. Launch index.html in a browser
